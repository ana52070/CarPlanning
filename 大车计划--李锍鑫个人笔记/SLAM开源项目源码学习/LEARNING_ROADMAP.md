# 开源自主导航系统学习路线图

这份文档旨在帮助您从零开始，循序渐进地掌握这个开源导航项目的核心原理与代码实现。考虑到您对算法理论和 NumPy 尚不熟悉，我们将学习过程分为五个阶段。

## 阶段一：基础铺垫 (准备工作)

在深入阅读核心代码之前，我们需要先扫清语言和数学上的障碍。

1.  **NumPy 极简入门 (针对本项目)**
    *   **目标**：读懂代码中的矩阵操作，不再对 `np.array`,切片, `mask` 感到恐惧。
    *   **重点**：
        *   数组形状 (`shape`) 与 重塑 (`reshape`)
        *   布尔索引 (Boolean Indexing / Masking)：代码中大量用于筛选障碍物。
        *   广播机制 (Broadcasting)：代码中用于快速计算膨胀层的技巧。
    *   **练习**：在 Python 终端中运行简单的 NumPy 示例。

2.  **ROS 2 坐标系与数据流**
    *   **目标**：理清数据在节点间是如何流动的。
    *   **重点**：
        *   `map` (地图) -> `odom` (里程计) -> `base_link` (机器人) 的 TF 树。
        *   本项目中特殊的 TF 处理方式（手动计算矩阵 vs `tf2`）。

## 阶段二：建图模块 (Mapping)

从最直观的“看见环境”开始。

1.  **点云坐标变换 (`points_pub_map.py`)**
    *   **原理**：如何利用旋转矩阵和平移向量，把相对于机器人的点云数据，转换到世界坐标系（地图）下。
    *   **代码焦点**：`odom_callback` 中构建旋转矩阵的数学逻辑；`pointcloud_callback` 中的矩阵乘法 `@`。

2.  **栅格地图生成 (`map_pub.py`)**
    *   **原理**：如何把连续的坐标点变成离散的网格 (Grid Map)。
    *   **难点解析**：障碍物膨胀 (Inflation)。代码中巧妙地使用了 NumPy 的“圆”形掩码来批量标记危险区域，而不是用慢速的循环。

## 阶段三：规划模块 (Global Planning)

机器人知道地图后，如何规划出一条路。

1.  **A* 算法原理 (通俗版)**
    *   **概念**：代价 (G) + 启发 (H) = 总评分 (F)。
    *   **可视化**：理解 OpenList (待检查) 和 ClosedList (已检查) 的工作流程。

2.  **A* 代码实战 (`astar.py`)**
    *   **代码焦点**：`astar` 函数。
    *   **细节**：
        *   `heapq` (优先队列) 是如何保证每次取出的都是评分最高的节点？
        *   8-邻域搜索 (上下左右+对角线)。
    
3.  **路径平滑**
    *   **概念**：为什么 A* 走出的折线不适合机器人？
    *   **代码焦点**：`bezier_smoothing` 函数。贝塞尔曲线是如何把折线变圆滑的。

## 阶段四：控制模块 (Local Control)

有了路径，如何让机器人照着走。

1.  **Pure Pursuit (纯追踪) 原理**
    *   **概念**：想象你在骑自行车，眼睛盯着前方一段距离的某个点（预瞄点），手把车头对准那个点骑过去。
    *   **几何模型**：利用三角形几何关系计算转向角 (Steering Angle)。

2.  **控制器实现 (`start_nav.py`)**
    *   **代码焦点**：`calculate_steering_angle` 方法。
    *   **细节**：
        *   如何寻找最近路径点？
        *   如何选取预瞄点 (Lookahead Point)？
        *   速度控制策略：拐弯时减速。

## 阶段五：整体串联与参数调试

1.  **系统启动流程**
    *   分析 Launch 文件，看节点启动顺序。

2.  **实操调试 (Gazebo)**
    *   **任务**：尝试修改 `start_nav.py` 中的 `lookahead_distance`，观察机器人走S弯还是走直线的区别。
    *   **任务**：尝试修改 `map_pub.py` 中的 `obstacle_radius`，观察地图上障碍物变大变小的效果。

---

**建议学习方法**：不要试图一次性看完所有代码。按照阶段，先看文档理解原理，再对照代码看实现，最后动手改参数看效果。
